## 1. The Modernization Motivation (or: Old Homepage Was Too Boring)

Part 1 gave us a top nav and filtered sidebar, but the homepage? It was just text: a hero block and a big dump of 24 series lists. No grid layout, no featured cards, no CTA buttons. The design needed breathing room. The goals for Part 2:

- Add a bold hero section with title, description, and "Browse Series" / "Latest Posts" buttons.
- Show 4 "Featured" posts in a responsive card grid.
- Put the remaining 6 recent posts in a separate "More Recent Posts" list.
- Collapse the 24 series into expand/collapse sections (24 clicks was too much).
- Make the whole page mobile-friendly (it broke above 60rem before).

## 2. Generator-First Approach

The homepage is auto-generated by `scripts/gen_home.py`. I modified `write_index()` to output the new structure instead of the old HTML blobs. The data pipeline stays the same:

- `collect()` knows about series and standalone posts.
- `write_index()` now picks top 4 as "featured", next 6 as "latest", and generates collapsible `<details>` for series.

```html
  <div class="cb-series__list">

      </ul>

    ...
  </div>
</section>
```

Key: `<details>` for native HTML collapsible (no JavaScript needed). Works in all browsers, accessible by default.

## 4. CSS Additions

Added to `docs/stylesheets/extra.css`:

```css
.cb-hero { ... }                    /* 4-line hero with centered content */
.cb-hero__cta { display: flex; }    /* Button row */
.cb-btn { padding, transition }     /* Two styles: primary (filled), secondary (outline) */
.cb-featured__grid { grid }         /* Auto-fit cards */
.cb-card { border, hover shadow }   /* Hover lift effect */
.cb-series__summary { cursor: pointer } /* Shows triangle arrow */
.cb-series__item[open] ... transform rotate(90deg) /* Arrow rotation */
```

Mobile: grid collapses to single column, sidebar moves below hero.

## 7. Design Decisions

| Choice | Why |
|------|-----|
| Native `<details>` | Zero JavaScript, accessible, cross-browser |
| Featured vs Latest | 4 cards feels right; 6+10 was too much |
| CTA buttons | Directs eye movement to the two main navigation paths |
| Grid cards | Works on mobile via `auto-fit, minmax(260px, 1fr)` |
