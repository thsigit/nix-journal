### 4.2 Updated attribution
Edited the skill’s **## 10. Publishing to GitHub Pages** section to remind users that the footer must show the actual model and provider (e.g., `Generated with Nemotron 3 Super (Nvidia)`). ### 4.3 Clarified publishing workflow
Added a whole new **## 10. Publishing to GitHub Pages** (formerly 9) that explains:
- The source repo stays on `main`; only the built site goes to `gh-pages`.
- The script `/srv/repo/nix-journal/scripts/publish.sh` builds with Zensical, sets `site_url` to the GitHub Pages URL, copies the output into a temporary directory, prepares/updates the `gh-pages` worktree, commits, and pushes to the `gh-pages` remote branch.

- The local preview (`https://homelab.home.arpa/journal/`) is served from `/srv/www/codebot/journal/`, which is kept in sync by the `zensical-build.service` (triggered by `zensical-build.path`) whenever source files change.
